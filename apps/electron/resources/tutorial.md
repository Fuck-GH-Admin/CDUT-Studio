# 第一部分　CDUT 专区

## 一、专区概览

CDUT 专区把校内数据与 AI 能力接到一起，由四部分组成：

| 组成 | 依赖 | 作用 |
| --- | --- | --- |
| **校内事务工具** | 需登录特区账户 | 由 Agent 调用 9 类校内工具，读写教务数据 |
| **AI 速课堂** | 需登录特区账户 | 上传课件建资料库，按知识点带教 |
| **智联万站** | 内嵌浏览器 | 自动浏览任意网站（校内站点为默认书签，不构成访问限制），桌宠「砚小龙」代为操作 |
| **材料审核** | 独立审核模型 | 按规则逐条比对申报材料与证明的偏差 |

校内事务工具与 AI 速课堂均以特区账户登录态为前提，未登录时相关调用会被拦截并提示登录。

## 二、特区账户

### 登录如何工作

填写 **学工号 + 密码**（可选勾选「记住密码」）后，客户端在后台以隐藏窗口完成校内统一身份认证（CAS）。密码只提交给校内认证页，渲染层不接触明文；勾选记住时，凭据经操作系统安全存储加密后落盘 `~/.cdutai/cdut-account.json`。

> **实际行为**：客户端每次启动都会复位会话并置为未登录，持久化凭据仅用于 **一键填充并登录**，不会自动登录。

> **先体验一下**：在侧栏进入 **CDUT 专区**，可用演示账号登录感受课表雷达、成绩与 GPA 透视、自习空教室检索等能力（学工号 `202520260101`，密码 `Nya315`）；密码同样只在后台提交给校内认证页，不会落盘明文。

### 画像抓取

登录成功后抓取并展示：姓名、学工号、学院、专业、身份、证件照。

抓取实现为多路兜底：

- **姓名**取三路之一：登录后页面顶栏直接解析 > 学籍卡片 > 学工号占位；
- **证件照**按三级降级：页面内 Canvas 直取 > 页面内带凭证请求转 Base64 > 主进程下载并按图片魔数校验；
- **学籍表格**同时兼容「标签与值同格」与「标签与值分列」两种版式；
- 头像抓取失败时继承上次缓存，不伪造；整段抓取异常时会以「学号即姓名」的降级结果判定登录成功。

> 因此可能出现「登录成功但部分画像为空」的情况，这是如实留空，不是数据错误。

### 保活与失效

- 每 **10 分钟**探活青果教务主框架；探活命中 CAS 登录页或返回 401/403 时，将状态置为 **已过期** 并停止探活；
- 「已登录」只表示最近一次认证成功且心跳未判失效，**不代表维持内网长连接**。

### 登出

点击 **退出特区账户** 会删除本地加密凭据、停止保活并清空专属浏览分区。

### 门禁

未登录时，Agent 调用任一校内事务工具都会触发门禁提示，说明当前尝试调用的能力仅对已登录账户开放，并提供登录入口。门禁在 120 秒内无响应即按拒绝处理。

## 三、校内事务工具

校内事务工具由 Agent 调用，共 9 类：8 个青果教务业务域 + 1 个校内反向代理接入。所有请求走账号专属会话分区访问 `jw.cdut.edu.cn`，未登录一律被门禁拦截。

### 只读能力

| 业务域 | 实际能力 |
| --- | --- |
| **学籍档案** | 学籍信息与证件照、联系方式、学籍异动、大类分流、辅修报名查询 |
| **课表** | 本人课表；按 **班级 / 教师 / 教室** 查全校课表；可指定学期与周次 |
| **成绩** | 历年成绩、等级考试成绩、社考置换记录、查卷进度；**GPA 与加权分由客户端本地计算** |
| **考务** | 期末考程、补考、重修、缓考状态 |
| **教室资源** | 成都 / 宜宾校区的空教室与占用；可按教学楼、周次、星期、节次、最少座位数筛选，并标注是否含空调 |
| **培养方案** | 培养方案、毕业学分完成率、学位申请状态、延毕信息 |
| **选课** | 选课轮次、可选课程、已选结果；可选课程支持按关键词、课程类别、是否仍有余额二次过滤 |
| **教务通知** | 通知、留言、FAQ、文档、学业预警、密码策略、当前登录身份 |

### 可写能力

以下操作会向教务系统提交变更，共 13 项，执行前一律弹出二次确认：

| 业务域 | 可写操作 |
| --- | --- |
| 学籍档案 | 提交大类分流志愿、辅修报名 |
| 成绩 | 申请社考置换、申请查卷 |
| 考务 | 补考报名、重修报名、缓考申请 |
| 培养方案 | 学位申请、延毕申请 |
| 选课 | 选课、退课 |
| 教务通知 | 留言提问、修改密码 |

### 行为与边界

- **二次确认**：写操作会请求你确认「AI 正在申请【某项操作】，是否执行？」；120 秒未响应或没有可用窗口即拒绝，绝不提交；该确认在演示态判定之前执行。
- **成功判定为启发式**：写操作以「HTTP 成功且响应正文不含失败/错误等字样」判定成功，并非读取服务端结构化结果，存在判定与实际不完全一致的可能。
- **不做通用自动重试**：除成绩查询有备用端点回退、登录头像有补抓外，其余请求一次失败即返回错误，不会自动重试。
- **登录失效**：会话过期时统一返回「请先重新登录」。
- **叠加通用审批**：校内工具不在通用只读白名单内，因此在「自动审批」模式下，除专属门禁与写确认外，还会再走一次通用工具审批。
- **反向代理工具**：第 9 类工具依赖外部端点配置，当前为预留状态，未配置时返回「预留」说明，不会伪造回答。

### 调用示例

已登录后在 Agent 会话中直接描述需求：

> 帮我查这周还剩哪些空教室，周二下午校本部第三教学楼，尽量两节课以上的连续空档。

> 我这学期还差多少学分才能毕业？对照培养方案列出来缺哪几类。

> 期末考程整理成一份按日期排序的清单，写到工作区的 `考程.md`。

> 看看补考报名开始没有，没开始就先别报。

## 四、AI 速课堂

### 隔离方式

每个「课堂」是一个独立会话，绑定专属工作区与专属导师提示词，资料与对话与其他课堂、其他 Agent 会话彼此隔离。进入前需先选择或新建课堂。

### 资料入库流程

上传后客户端按文件类型解析，再按语义切块（约 1200~2600 字/块）建立索引：

| 文件类型 | 处理方式 |
| --- | --- |
| PDF | 高精解析，保留页级锚点 |
| Word / PPT / Excel | 双平面解析，保留页 / 幻灯片 / 工作表锚点 |
| Markdown / HTML / 文本 | 按标题、列表、段落切块 |
| 图片 | 尝试本地离线文字识别；不可用时降级为视觉引用块 |

> **现状**：随包未提供文字识别所需的资源，扫描件与图片的文字识别当前不生效；图片改以视觉方式直接交给多模态模型。

每份资料有**激活开关**：只有已激活的资料参与检索与讲解，未激活的资料会被排除在检索与提示词之外。支持格式为 `PPT/PPTX/PPSX/POTX`、`PDF`、`DOC/DOCX`、`XLS/XLSX/XLSM`、`MD/Markdown`、`HTML`、`TXT`、`PNG/JPG/JPEG/WEBP/BMP`。

### 检索引擎

速课堂提供两组可选引擎（本地运行，下一轮提问生效）：

| 引擎组 | 选项 | 实现 |
| --- | --- | --- |
| 课堂资料检索 | **精准查点**（默认） | 全文索引 + 向量混合切块检索 |
| | **全书脉络** | Leiden 分层社群图谱检索，适合宏观、跨章节问题 |
| 跨课记忆检索 | **当堂专注**（默认） | 词法时间线检索 |
| | **海马体跨课联想** | 多跳图谱扩散检索，适合跨学期联想 |

### 知识图谱

「资料树」是一张知识图谱，**只在你主动触发时构建**，不会随资料变更或会话加载自动消耗 Token。构建提供三档方案：

| 方案 | 做法 | 成本 |
| --- | --- | --- |
| 纯本地生成 | 本地启发式关联 | 0 Token |
| 云端智能精炼（推荐） | 先剔除前言 / 目录 / 致谢，再送核心考点给模型 | 按量计费 |
| 云端全量精读 | 全量逐段精读 | 成本最高 |

生成的图谱会缓存，节点间关联分前置 / 题型 / 延伸 / 关联四类；模型不可用时降级为本地关联。

### 认知档案与专属工具

- 带教过程会维护一份认知档案，维度为 **已掌握 / 待学未知 / 薄弱混淆**，供后续靶向讲解；
- 速课堂内可使用三件事：查阅某章节原文、跨资料检索、读写认知档案。

### 边界

- 必须在专区内交互；在专区外打开课堂会话时输入区会被锁定；
- 会话内禁用 `/` `#` `&` 唤起，只保留资料引用（引用为带块号的定位标记，点击跳转并高亮原文）；
- 未登录时课堂内容区被替换为登录提示。

## 五、智联万站

### 是一个可编程浏览器

智联万站是内嵌的浏览器，具备标签栏、地址栏与 4 个校内书签（办事大厅、青果教务、图书馆、研究生院），默认首页为办事大厅。校内书签仅为默认收藏，不构成访问限制（站外 `http` / `https` 一律放行）。

- **休眠策略**：后台标签超过 10 个且闲置超 30 分钟时释放其运行实例（元数据保留，点开即恢复）；
- **状态持久化**：标签状态保存在 `~/.cdutai/yanhu-express/tabs.json`，重启后恢复。

### 访问策略

- 站外 `http` / `https` 一律放行，不限制校内域名；
- 仅拦截非网页协议（`mailto:` / `javascript:` / `file:` 等）与无法识别的输入，此时可用「系统浏览器打开」；
- 不提供搜索，输入域名会自动补全 `https://`；
- 加载失败时提供「净化缓存并重试」，该操作会先清除失效的瑞数签名再重载。

### 桌宠「砚小龙」

进入智联万站时砚小龙自动出现，是常驻浮窗，通过自然语言指挥它操作当前网页。

- **能力边界**：砚小龙运行在精简运行时上，只有对话、记忆与工具调用三类能力，**不挂载本机文件系统、终端与子 Agent 委派**，全部动作发生在浏览器内；
- **记忆**：对话记忆按条数上限保留（可在 0~1000 条间设置），落盘保存；
- **模型**：可在 **设置 → 模型配置 → 智联万站专属模型** 单独指定渠道与模型，未配置时继承全局默认；
- **设置**：右键桌宠立绘可调整位置、显示形态、对话框朝向、记忆条数与清空记忆。

### 浏览器工具

砚小龙具备 15 项浏览器工具：11 项通用 + 4 项开发者级。

| 能力 | 实际行为 |
| --- | --- |
| 读页 | 结构化读取当前页面，含表格快照与控件编号 |
| 点击 | 点击按钮 / 链接，优先使用底层调试协议，失败回退常规点击 |
| 填写 | 向输入框写入文本 |
| 选择 | 操作下拉、单选组等控件 |
| 滚动 / 导航 / 前进 / 后退 / 刷新 | 常规浏览动作 |
| 标签操作 | 新建 / 关闭 / 切换标签 |
| 文件上传 | 向上传控件注入本机文件 |

4 项开发者级工具默认关闭（执行页面脚本、检查元素、读取网络日志、读取控制台日志），需显式开启后生效。

### 行为护栏

> 在砚小龙输入条发送 `/development-DevTool-MCC` 可开启开发者级工具并唤起诊断控制台，用于排障，日常无需接触。

- **危险操作拦截**：命中注销 / 退出登录 / 退出系统等语义时直接拒绝；
- **重复点击拦截**：同一控件再次点击且页面内容完全没变时拦截，并建议改用选择或填写；
- **死锁防护**：检测到两个控件来回振荡点击时熔断；
- **拟人化节流**：网络级动作保留固定间隔，避免被教务系统判定为机器人而掉登录态；
- **教务主框架保护**：在教务主框架内导航 / 刷新时只作用于内层框架，避免外框撕裂白屏，并自动剥离一次性票据；
- **一次签名清洗**：每次请求前清除失效的瑞数动态签名，避免网关返回空响应导致的刷新死锁。

诊断控制台可收集页面控制台输出、导航与加载生命周期、网络报文以及底层抓包日志，最多保留 3000 条。

## 六、材料审核

材料审核里有两条并存的路线：**预审工作台**是当前完整可用的主线；**V2 案卷 / 模板编排 / 批次管理**是把同一审核过程抽象成「模板 + 政策 + 规则」的进阶体系，功能已实现但界面铺开有限。

### 6.1 预审工作台（主线）

```mermaid
flowchart LR
  A["导入依据 / 待审 / 证明"] --> B["生成 AI 规则大纲"]
  B --> C["识别可审核条目"]
  C --> D["AI 审核员逐条比对"]
  D --> E["问题卡三栏联动"]
  E --> F["导出预审报告"]
```

**导入材料**：按角色分别导入 **审核依据（规则）**、**待审文件**、**证明材料**。支持 `md/txt/csv/json/svg`、`pdf/doc/docx/xls/xlsx/ppt/pptx`、`png/jpg/jpeg/gif/webp/bmp`，单文件上限 50MB。导入后按文件类型解析切块：PDF 与 Office 走高精引擎保留页 / 幻灯片 / 表格结构；文本按标题、列表、段落切块；解析不出文本时标记为「未提取到文本」，不假装成功。

**生成规则大纲**：由模型从依据文件中提取规则条目（类别、标题、摘要、原文定位），领域包只提供建议类别。**大纲当前不可手工编辑或增删**。

**识别可审核条目**：把全部待审文件的文本与图片（图片以视觉方式，单次最多 8 张、单张 8MB）交给多模态模型，产出条目及其类别、等级、申报分、关联证明与原文定位。

**开始审核**：把依据、待审、证明与条目一并交给模型逐条比对，产出问题卡，字段包括类型、严重度、说明、建议与三处定位（待审 / 证明 / 对照）。严重度取模型判定，缺失时按领域包对该问题类型的默认值，未知类型回落为黄色。

**结果定位与导出**：点击问题卡会三栏联动高亮（中栏红黄、左栏蓝色），跨文件矛盾则两处同色高亮。审核助手（`Ctrl/⌘ + Shift + A`）可就该案卷追问。报告导出为 JSON + Markdown 两份，前提是存在一次完整通过的审核且**案卷未被修改**，否则提示「结果过期，请重审」。

**覆盖摘要四格的口径**：

| 格子 | 统计口径 |
| --- | --- |
| 已审核 | 恒等于全部条目数，**不是实际被核对的条目数** |
| 待人工复核 | 建议为「人工复核」，或命中缺证明 / 证明看不清的条目 |
| 未识别文件 | 解析失败，或解析为空的文件 |
| 规则未覆盖 | 未命中任何规则约束的条目 |

只要存在未处理材料，「全部符合」的结论不成立，界面会单独提示。

### 6.2 需要如实知道的现状

- **证明卡状态不会自动更新**：新导入的证明一律标记为「未提取事实」，系统对用户自建案卷**不会自动识别证明内容**，也不会把它升级为「已识别」或「看不清」——「看不清」目前只出现在内置演示案卷中；
- **文字识别不可用**：随包未提供识别资源，扫描件与图片的文字识别不生效，图片只能作为视觉输入交给多模态模型；
- **无整卷导入 / 导出**：只能导入材料、导出预审报告，不能导出整个案卷；
- **审核模型出口受限**：只允许「OpenAI 兼容」「自定义」「Ollama」三类本地或自建出口，理由是避免案卷外发；实际取第一个可用渠道，没有模型选择界面；单次审核超时约 150 秒。

### 6.3 领域包

内置 4 个领域包，提供建议类别与各问题类型的默认严重度：**学生综合素质测评**（默认）、**合同 / 协议审批**、**费用报销审批**、**自定义审核**。指定未知领域包时审核会显式报错，不静默回落。

### 6.4 V2 案卷 / 模板编排 / 批次管理

这三个页签把审核扩展为带流程的体系：

- **模板编排**：六步向导定义名称、对象类型、字段、材料槽、是否评分与负责人规则，把规则文本编译为政策并发布模板版本；
- **V2 案卷**：从已发布模板建案、登记材料（同名同槽再登记会形成新版本，旧版退出审核）、提交，并按阶段推进（阶段通过 / 退回补件 / 最终驳回 / 撤回 / 评委评分 / 补件回复 / 申诉）；
- **批次管理**：创建批次时锁定模板与政策版本，逐个案卷排队执行，定稿生成快照且不改写历史，可基于定稿重开新一轮。

> 现状：这套体系的底层能力（版本链、评分、补件与申诉闭环、检查点续跑、离线交接包等）已实现，但多数入口尚未接线到界面，可在界面操作的部分以案卷登记与业务流程为主。

## 七、专区答疑

<details>
<summary>专区首页的课表 / 成绩快捷入口点了没反应？</summary>

首页底部四个快捷胶囊目前是占位入口。校内数据请直接对 Agent 说需求（见第三章），例如「查我这周的空教室」。

</details>

<details>
<summary>登录后仍提示需要登录？</summary>

客户端每次启动都需重新登录，且登录态失效（探活命中登录页或 401/403）后会置为已过期。回到 CDUT 专区重新登录即可。

</details>

<details>
<summary>登录成功但姓名 / 头像缺失？</summary>

画像由多路兜底抓取，个别接口失败时会如实留空或沿用缓存，不会伪造。可稍后重新登录再试。

</details>

<details>
<summary>AI 速课堂打不开 / 提示内容受限？</summary>

速课堂仅对已登录账户开放，且必须在专区内的课堂中交互；在专区外打开课堂会话时输入区会被锁定。

</details>

<details>
<summary>资料树一直是空的？</summary>

资料树只在你主动点击生成时构建。先勾选要参与的资料，再生成。

</details>

<details>
<summary>材料审核的「全部符合」点不了？</summary>

只要还有未处理材料，该结论就不成立；处理完剩余材料或重新审核后再导出。

</details>

<details>
<summary>材料审核报告导出按钮不可用？</summary>

需要存在一次完整通过的审核，且案卷此后未被修改；否则提示结果过期，需重新审核。

</details>

<details>
<summary>砚小龙怎么设置？</summary>

右键桌宠立绘打开设置菜单，可调整位置、显示形态、对话框朝向、记忆条数与清空记忆。

</details>

# 第二部分　Agent 基础

## 八、运行环境与模型

### 内核与模式

客户端以 Pi 内核为唯一执行内核，当前为 Agent 单一模式；此前的 Chat 对话模式已移除。

Agent 的文件与能力围绕**工作区**组织：一个工作区拥有自己的文件、会话、Skills、MCP 与预设。未指定工作区时，会话会落在默认工作区沙箱内，仍保留子 Agent 委派、任务图与记忆能力。

### 模型配置

在 **设置 → 模型配置** 添加渠道：

1. 选择供应商类型（国内常用：DeepSeek / 通义千问 / 智谱 / 豆包 / Kimi / MiniMax / 小米；通用：Anthropic 兼容 / Ollama / 自定义）；
2. 填写名称、Base URL、API Key；
3. 测试连接；
4. 从供应商获取并勾选要启用的模型。

配置与密钥默认保存在本机（`~/.cdutai/`），核心能力无需登录；API Key 本地加密存储（优先操作系统安全存储，不可用时回退 AES-256-GCM）。该页底部另可配置智联万站专属模型。

### 环境检测

**设置 → 关于** 可检测 Node.js、Git 以及 Windows 下的 Shell 环境（Git Bash / WSL）。客户端在 Windows 上会按 Git Bash > 内置 BusyBox > WSL > 原生 PowerShell 的顺序自动选择执行环境，无需手动配置。

## 九、Agent 能力

### 输入与引用

输入框支持四类引用：`@` 文件或目录、`/` Skill、`#` MCP 服务、`&` 其他会话。

### 执行控制

| 能力 | 实际作用 |
| --- | --- |
| **模型** | 选择本轮使用的模型 |
| **权限模式** | 自动审批 / 完全自动 / 计划模式 |
| **预设** | 切换岗位配置，下一轮生效 |
| **思考设置 / 推理档位** | 调整思考强度（低 / 中 / 高 / 最大）或推理档位 |
| **添加文件或文件夹** | 添加文件，或附加保留在原位置的目录 |
| **记忆开 / 关** | 关闭为单轮聚焦，开启为多轮对话 |
| **上下文用量** | 显示占用比例，长按可手动压缩上下文 |

权限三种模式的区别：**自动审批**由审批器判断，危险操作仍会请求确认；**完全自动**尽量不打断，适合边界明确、低风险的任务；**计划模式**先调研并给出方案，批准后才执行写入。

### 任务可观测

- **任务图**：以思维导图呈现任务进度、依赖、执行用量与放弃的分支，可跳转到对应执行会话；
- **目标（Goal）**：会话顶部状态条，支持编辑、暂停、恢复、停止，并可查看验收契约、预算与证据；
- **协作子 Agent**：复杂可并行任务会派出子会话独立推进，再汇总结果。

### 历史与分支

每条用户提问支持 **撤销本轮及之后对话并重新编辑**；每条助手回复支持 **从此处分叉**（以该点为起点新建独立会话，可换模型接续）与 **从此处探索**（保留主线，另开分支）。

### 上下文与文件

三类文件：**会话文件**（仅本会话）、**工作区文件**（所有会话共享）、**附加文件 / 目录**（保留在原位置）。过程文件（进度、计划、调研结论、交接信息）会沉淀在工作区 `.context/` 下。

建议一个会话围绕一个目标，阶段完成后把结论写入工作区文件，再新建会话继续。

# 第三部分　其他能力

## 十、技能与记忆

左侧栏 **Agent 技能** 管理工作区能力，包含 Skills、MCP、记忆、预设（团队工作区另有团队市场），并提供跨工作区生效的全局配置。

**Skills**：`SKILL.md` 及其资源构成的工作手册，Agent 匹配任务时加载。内置 17 个：工作流类（`brainstorming`、`writing-plans`、`executing-plans`、`find-skills`、`skill-creator`、`automation`）、文档类（`docx`、`xlsx`、`pptx`、`pdf`、`guizang-ppt-skill`）、平台类（`in-app-browser`、`lark-delivery`、`tool-builder`、`session-cleaner`）、个性化（`user-sense`、`profer-coach`）。

**MCP**：连接外部服务，支持 `stdio` / `http` / `sse` 三种传输。必须先测试连接成功才能启用，改动配置会自动关闭并清空测试结果。官方托管的 `lark-mcp` 在 **设置 → 远程连接 → 飞书** 中管理。

**记忆**：分三层——工作区资料（`workspace-profile.md`，项目规则与常用命令）、自动记忆（`.cdutai/memory/MEMORY.md`）、长期经验归档。支持 `[[双链]]` 跳转与反链、从历史会话生成记忆、空闲时对旧记忆做整理（不做删除，不伪造内容）。

**预设**：把提示词、推理强度、权限模式、Skill / MCP 白名单、能力裁剪与子 Agent 委派开关打包成可复用配置。内置 **标准 / 代码 / 极简**。

---

## 十一、规划与自动化

**规划中心**包含三个部分：

- **Todo**：待办清单，支持分组、优先级、计划完成时间与标签，可直接从待办发起 Agent 会话；
- **日程**：月 / 周视图，支持拖拽创建并关联 Todo 与标签；
- **定时任务**：周期任务的创建、编辑、暂停、立即运行与删除。

**定时任务**用于长期反复、可无人值守的流程，支持四种频率：每隔一段时间、每天定点、每周定点、每月定点（可多时刻多选）。还需指定模型、工作区（必选）、预设、运行权限（完全自动 / 自动审批），可选飞书通知（成功或失败都通知 / 仅成功 / 仅失败）。

后台约束：单次执行超时约 2 小时；任务持续失败会自动暂停；机器忙碌时跳过本轮而不排队。任务描述只写业务目标，不要写密钥。

**设置 → 远程连接** 可接入即时通讯平台，实现远程派发任务：

| 平台 | 能力 |
| --- | --- |
| **飞书** | 扫码创建或绑定机器人；支持会话镜像、工作区飞书能力与云端授权 |

| **钉钉** | 多机器人配置与连接状态 |

常用命令：`/help`、`/new`、`/list`、`/stop`、`/switch`、`/workspace`、`/model`、`/now`。远程执行前应先配好工作区、模型与权限边界。

## 十四、安全与边界

- **本地优先**：配置与数据默认保存在本机，核心能力无需登录；
- **密钥加密**：API Key 与特区账户密码均本地加密存储，不明文落盘；
- **敏感信息**：不要把 API Key、密码、令牌写进文件、Skill、定时任务或聊天内容；
- **统一身份认证**：密码只提交给校内认证页，渲染层不接触明文；
- **受管边界**：智联万站的桌宠不挂载本机文件系统与终端；远程机器人应在配置好的工作区与权限边界内运行；
- **备份**：个人备份可能含密钥，只保存到可信位置；
- **第三方资源**：安装来源不明的 MCP / Skill / 脚本前，先核对来源、权限与实际执行命令。

## 十五、常见问题

<details>
<summary>模型不在选择器里？</summary>

确认渠道已启用且勾选了模型，并检查供应商类型、Base URL 与连通性测试。

</details>

<details>
<summary>Agent 读不到我的文件？</summary>

检查是否已建 / 选工作区、是否用 `@` 引用、附加目录是否已授权、路径是否正确。

</details>

<details>
<summary>MCP 没有工具或连接失败？</summary>

在 **Agent 技能 → MCP** 确认测试连接成功且开关已启用，再检查命令 / URL / 环境变量与外部服务。

</details>

<details>
<summary>长会话变慢、答非所问？</summary>

把阶段结论写入工作区文件，用上下文用量手动压缩，或新建会话只引用必要资料。

</details>

<details>
<summary>Agent 改完结果不对？</summary>

打开 **文件改动** 与 **任务图** 复核它做了什么，明确验收条件后让它修正；高风险操作先回退或停止。

</details>

## 结语

建议的使用顺序：先在 CDUT 专区登录，用 Agent 调用校内工具处理课表、成绩、空教室等事务；需要学习辅导时用 AI 速课堂；需要上网办事时用智联万站；材料复核用材料审核。其余通用任务（文档、代码、资料整理、周期流程）按需使用 Agent 的对应能力。
